### a) Como a memória é alocada?

 -> Arrays primitivos, como int[] e double[], armazenam diretamente os valores dos tipos correspondentes. Arrays de objetos, como Aluno[] e Produto[], armazenam referências aos objetos, que são criados separadamente na memória.

### b) Quais cuidados devem ser tomados?

 -> É necessário verificar se o índice está dentro dos limites do array e, no caso de arrays de objetos, verificar se o elemento não é null antes de acessar seus atributos ou métodos, evitando erros.
